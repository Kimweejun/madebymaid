# AI 기술·분야 태그 (madebymaid-tagging)

받아 온 것과 만드는 것을 **같은 두 기준**으로 나눈다. 박스마다 제목 아래 태그로 보이고, 태그를 누르면 같은 태그가 붙은 모든 것을 한 창에 모아 본다.

- 기준표: `komow-local/tags.json` (태그 목록·낱말·도구 30개 태그)
- 계산기: `komow-local/tagging.py`
- 직접 고친 것: `komow-local/data/tags_override.json` · 렘이 분류한 것: `data/tags_ai.json`
- 사용자 결정: 2026-10-14 (목록, 기준마다 최대 2개, 섞어 쓰기, 태그 클릭 모아 보기)

## 두 기준

| AI 기술 (무엇으로) | 분야 (어디에) |
|---|---|
| 언어·LLM · 에이전트·자동화 · 음성 · 비전 · 이미지·영상 생성 · 데이터·시각화 · 3D·그래픽·GPU · 로보틱스·제어 · 인프라·온디바이스 · 개발 도구 · AI 아님 | 국방·안보 · 제조·로봇 · 푸드·외식 · 콘텐츠·미디어 · 공공·문서 · 홍보·마케팅 · 개발·연구 · 업무 일반 |

AI 기술 태그가 하나도 없으면 **미분류**. 분야는 비어 있어도 된다.

## 붙는 순서 (앞이 이김)

1. **직접 고친 태그** (박스의 ✎) — 둘 다 비우면 자동으로 되돌아감
2. **처음 정해 둔 태그** — 작업 공방 도구 30개 (`tags.json`의 `tools`)
3. **낱말 규칙** — 제목·설명·저장소 이름에서 기준표 낱말을 세어 많이 걸린 순서로 기준마다 최대 2개. 짧은 영문(mcp, gpu, ros)은 단어로 따로 있을 때만.
4. **렘의 분류** — 규칙으로 미분류인 것만

## 렘이 분류할 때 (하루 한 번, 또는 "미분류" 창의 "지금 렘에게 맡기기")

1. 작업 폴더 `통합서버\실험실\TAGS-날짜\items.json`을 읽는다: `[{key, title, text, where}]` (최대 100개).
2. 항목마다 **제목과 설명만 보고** 고른다. 인터넷 검색·설치는 하지 않는다.
   - AI 기술: 위 목록에서 최대 2개, AI와 무관하면 `AI 아님`
   - 분야: 위 목록에서 최대 2개, 맞는 게 없으면 빈 목록
   - 목록에 없는 이름은 쓰지 않는다 (서버가 버린다).
3. 같은 폴더에 `result.json`으로 저장: `{"<key>": {"tech": [...], "field": [...]}, ...}` (모든 key 포함).
4. 서버가 끝나는 즉시 합쳐서 다음 화면부터 반영한다. 한 번 물어본 항목은 다시 묻지 않는다.

## 기준을 바꾸고 싶을 때

- 낱말 추가·삭제: `tags.json`만 고치면 바로 반영 (서버 재시작 불필요).
- 태그 이름 자체를 바꾸거나 늘리면 직접 고친 태그·렘 분류와 어긋날 수 있으니, 바꿀 내용과 이유를 사용자에게 먼저 제안한다.
