# PPT 디자인 (madebymaid-ppt-design)

기준: Claude에 저장된 **A4AI 발표 디자인 시스템** (https://claude.ai/artifact/HFEdmyrnJye1p36d4jRv3p).
모양은 `komow-local/ppt/deck.py`가 PPT와 웹 슬라이드에 **똑같이** 적용한다. 렘·람은 내용(deck.json)과 색 선택만 하고, 모양을 바꾸고 싶으면 `deck.py`를 고치자고 사용자에게 먼저 제안한다.

## 틀 (디자인 시스템 그대로)

- 1920×1080 기준. 여백 위 60 · 좌우 76 · 아래 56px. PPT는 같은 배치를 13.33×7.5인치로 옮김.
- 글꼴 Noto Sans KR. 제목 50px 900(결론 문장), 부제 23px `muted`, 본문 28px, 출처 16px, 용어 풀이 17px.
- 바탕: 일반 슬라이드는 흰색(`paper`), **표지만** 테마의 어두운 색.
- 본문 슬라이드: 제목·부제 → 전체 폭 본문 box(위쪽 3px 선 + 8px 둥근 사각 점 목록) → 아래 **band**("핵심" 한 줄, 선택) → 출처·용어 풀이(선택) → 하단 `실험번호 · 제목`과 `n / 전체`.
- 결론 슬라이드: 제목 = 결론 한 줄, 판정 tag(알약 모양) + "근거" box · "다음 할 일" box 두 칸.
- 그래프·그림이 있는 슬라이드: 왼쪽 본문 목록(약 700px) · 오른쪽 그래프나 그림(약 1030px). 그래프는 PPT 안에서 고칠 수 있는 차트로 들어가고 색은 테마 주색·포인트색·회색 순. 그림은 늘이지 않고 잘라 채우며, 아래에 작은 글씨(17px)로 해설, 그 아래 출처(16px).
- 도식(`diagram`) 슬라이드: 기본은 오른쪽 칸 **1028×728**(본문 목록 옆), `"layout": "full"`이면 본문 목록 없이 **전체 폭 1768×728**(핵심 한 줄은 band로). SVG `viewBox`를 이 크기(`0 0 1028 728` / `0 0 1768 728`)로 그리면 잘리거나 여백 없이 꼭 맞는다. 색은 보고서 테마를 따라 `var(--main)` `var(--soft)` `var(--point)` `var(--ink)` `var(--muted)` `var(--line)`를 쓸 수 있다(그림으로 바꿀 때 `deck.py`가 채워 줌). 그림 변환은 이 PC의 Microsoft Edge로 한다.
- **핵심 요약은 슬라이드 안에 넣지 않는다.** 웹 페이지에서 각 슬라이드 그림 **옆**에 따로 보여 준다.

## 웹 페이지

- PowerPoint가 만든 **실제 슬라이드 그림**(PNG)을 왼쪽에, 그 슬라이드의 **핵심 요약**을 오른쪽 칸에 둔다. 좁은 화면에서는 그림 아래로 내려간다.
- 그림은 HTML 파일 안에 넣어(한 파일) 산출물 정리로 옮겨도 깨지지 않는다. PowerPoint가 없는 컴퓨터에서는 같은 모양을 HTML로 그려 대신한다.
- **로고는 넣지 않는다** (공개 저장소에 올라감, 사용자 결정 2026-10-14).
- 쓰지 않는 것: 왼쪽 세로선 카드, 그림자, 파랑·보라 그라데이션, 이모지 카드.

## 색: PPT 전체의 테마 세트

보고서마다 **테마 세트 하나**를 골라(`theme`) PPT 전체와 웹 페이지에 똑같이 쓴다. 슬라이드마다 색을 바꾸지 않는다. 각 세트는 조화를 맞춘 세 색으로 이뤄진다: **주색**(선·목록 점·판정 tag·band 글자, 흰 바탕과 옅은 바탕 모두 4.5:1 이상), **포인트색**(목차 번호·표지 강조선), **어두운 색**(표지 바탕). 옅은 색은 band 바탕.

| 테마 | 주색 | 포인트 | 표지 | 어울리는 보고서 |
|---|---|---|---|---|
| 현장 | 올리브 #3F5A3A | 앰버 | 짙은 녹흑 | 국방·제조·현장 (디자인 시스템 기본) |
| 기술 | 남색 #2F4A6B | 앰버 | 짙은 남흑 | 모델·도구·인프라 |
| 데이터 | 청록 #255B55 | 앰버 | 짙은 청흑 | 성능·지표·비교 |
| 사업 | 벽돌 #8E3427 | 앰버 | 짙은 적흑 | 시장·비용·지원사업 |
| 연구 | 자두 #5E3F61 | 청록 | 짙은 자흑 | 논문·리서치·트렌드 |

- 세트 밖의 색을 새로 쓰지 않는다. 새 세트가 필요하면 `deck.py`의 `THEMES`에 추가하자고 제안한다.
