# 이미지 생성 (madebymaid-image-gen)

## 언제

`deck.py`가 `EXP-번호_이미지프롬프트.md`를 남기면(본문 3장마다 그림 1개를 사진으로 못 채운 경우), 작업 공방 > 실험 카드에 **"그림 생성 필요"** 와 렘용 지시문이 생긴다. 사용자가 그 지시문을 렘에게 붙여 넣는다.

## 누가

- **기본은 렘**(ChatGPT·Codex의 이미지 생성). 보고서를 람이 만들었어도 그림은 렘이 만든다.
- 사용자가 다른 도구·다른 메이드·다른 화풍을 지시하면 **그 지시가 우선**이다 (사용자 결정 2026-10-14).
- 지금 쓰는 곳에서 이미지 생성을 쓸 수 없으면, 프롬프트를 그대로 보여 주고 사용자에게 ChatGPT에서 만들어 작업 폴더에 넣어 달라고 요청한다. 다른 유료 API를 임의로 쓰지 않는다.

## 순서

1. `통합서버\outputs\<렘|람>\EXP-번호_이미지프롬프트.md`를 읽는다 (슬라이드 번호별 프롬프트).
2. 슬라이드마다 그림 하나를 만든다.
   - 16:9에 가까운 가로 그림, 흰 바탕 또는 밝은 바탕, 보고서 테마 색(deck.json의 `theme`)을 강조색으로.
   - 실제 인물 얼굴, 실존 기업 로고·상표, 글자가 많은 그림은 피한다. 실제 결과·장비 사진을 흉내 내지 않는다.
3. `통합서버\실험실\EXP-번호\images\<슬라이드번호>.png` 로 저장한다.
4. 작업 폴더의 `deck.json`에서 그 슬라이드의 `visual`을 바꾼다:
   `{"type": "image", "file": "images/5.png", "generated": true, "caption": "(원래 caption 그대로)"}` — `prompt`는 지운다.
5. `python "C:\Users\user\Desktop\통합서버\komow-local\ppt\deck.py" publish deck.json` — 확인 없이 다시 올린다.
   해설 앞에 "개념 이미지 (AI 생성)"이 자동으로 붙고, 남은 프롬프트가 없으면 실험 카드의 "그림 생성 필요"가 사라진다.

## 사진과 생성 그림의 구분

- 기사·자료 사진: `file` + `source`(출처 필수). 공개 보고서지만 사용자 본인이 주소로 보는 용도라 **출처 표기로 충분** (사용자 결정 2026-10-14).
- 생성 그림: `file` + `generated: true`. 출처 대신 "개념 이미지 (AI 생성)" 표기.
