# 실험하기 스킬 (madebymaid-experiment)

API 키 없이, **실험 번호 하나**로 지시 → 결과 → 기록을 묶는다.

- 지시문 만드는 곳: `komow-local/workspace.py` (`EXP_KINDS`, `exp_prompt`)
- 결과 연결: `store_file` → `link_experiment` (파일 이름의 번호를 읽음)
- 기록: `komow-local/data/experiments.json`
- 화면: 커뮤니티·뉴스룸의 **실험하기** 버튼 → 작업 공방 > **실험** 탭

## 흐름

1. 커뮤니티(GitHub·Reddit)나 뉴스룸에서 **실험하기** → 종류와 렘·람(또는 둘 다)을 고른다.
2. 서버가 번호 `EXP-MMDD-NN`(그날 순번)을 매기고, 맡은 메이드마다 지시문을 만든다. 기록 상태는 **지시함**.
3. 지시문을 복사해 렘은 Codex Desktop, 람은 Claude Code에 붙여 넣는다.
4. 메이드가 `통합서버\outputs\렘` 또는 `outputs\람`에 `EXP-번호_제목.md`로 결과를 저장한다.
5. 30초 안에 산출물 정리로 자동 보관되고(폴더 = 렘/람), 같은 번호의 실험 기록에 붙어 상태가 **결과 도착**이 된다.
6. 결과를 읽고 별점·메모를 남기면 **평가 완료**.

ChatGPT 웹처럼 로컬 폴더에 못 쓰는 곳의 결과는, 파일 이름을 `EXP-번호_…`로 해서 산출물 정리에 직접 올리면 같은 기록에 붙는다 (폴더를 `렘`/`람`으로 하면 그 메이드 칸에 붙음).

## 실험 종류

| 종류 | 메이드가 하는 일 | 결과물 |
|---|---|---|
| 써보기 (`try`) | 저장소·도구를 실험 폴더에서 설치·실행해 보고 되는지 확인 | 실행 보고서 |
| 스킬로 만들기 (`skill`) | 방법을 우리 스킬로 정리 | 보고서 + `EXP-번호_SKILL.md` |
| 적용 검토 (`review`) | A4AI 업무에 쓸 수 있는지 판단 | 1쪽 검토서 |
| PPT로 분석하기 (`ppt`) | `madebymaid-ppt-analysis` 스킬대로 8~12장 분석 | `.pptx` + 웹 슬라이드 주소(GitHub Pages) |

같은 실험을 렘·람 둘 다에게 주면 작업 공방 > 실험에서 결과를 나란히 비교한다.

## 지시문 규칙 (메이드가 지킬 것)

- 작업 폴더: `통합서버\실험실\EXP-번호` — 없으면 만들고, **그 밖은 건드리지 않는다**.
- 프로그램·패키지 설치나 설치 스크립트 실행 전에는 무엇을 설치하는지 알리고 **사용자 확인**을 받는다.
- 비밀번호·API 키를 쓰지 않는다.
- 결과 파일 이름은 반드시 `EXP-번호`로 시작한다. (이 번호가 유일한 연결 고리)
- 보고서 형식(마크다운): `# EXP-번호 제목` / 한 줄 결론 / `## 해 본 것` / `## 결과` / `## A4AI 적용` / `## 다음 단계`

## 바꾸고 싶을 때

종류·문구·규칙을 바꾸려면 `workspace.py`의 `EXP_KINDS`와 `exp_prompt`를 고친다. 렘·람이 스스로 바꾸지 말고 바꿀 내용과 이유를 먼저 사용자에게 제안한다.
